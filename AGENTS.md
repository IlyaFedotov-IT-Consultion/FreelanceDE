# Editing the freelancer guide

The Russian and English editions live in `articles/2025/freelancer-gewerbe-guide.md`
and `articles/2025/freelancer-gewerbe-guide-en.md`. Read [STYLEGUIDE.md](STYLEGUIDE.md)
for Markdown conventions. The local Russian WordPress export is
`blog/freelance-guide.ru.html`. Edit the Markdown first.

- Keep the voice of a friendly, experienced professional. Preserve the author's
  examples, first-person observations and transitions. When one sentence gives
  the wrong impression, correct that passage in context.
- Explain a legal or tax rule where the reader needs it. Say whom it affects,
  what they need to do and which exception changes the answer. Place the
  official source alongside the explanation. Date thresholds and historical
  provider comparisons so readers can tell which figures apply to them.
- For a guide-wide revision, identify the Git revision before the first edits
  and also inspect uncommitted work. Compare the editions separately, section
  by section, for lost explanations, procedures, tables, illustrations and
  examples. Word or line counts alone cannot establish that the content survived.
- Preserve useful details in each language and carry applicable factual
  corrections into both editions. In the handoff, identify substantive passages
  removed or moved and explain why. Check internal links and image paths, plus
  existing public anchors when preparing the WordPress export.
- Commits, pushes and WordPress publication each require the user's explicit
  authorization. Follow the user's active agent configuration for delegation.
